How to Use Fonts for Print

Prevent font substitution, text reflow, and hairline dropout by embedding fonts properly or outlining vector display type.

Typography 5 Min Guide Embed vs. Outlines
Home / Resources / How-To Guides / How to Use Fonts

Why Fonts Break in Print Production

When a layout file opens on a prepress workstation that lacks your exact licensed font files, the application silently substitutes a default system font. Line breaks shift, bullets turn into stray glyphs, and carefully balanced columns overflow.

Two dependable workflows prevent substitution completely: embedding fonts inside a PDF/X export, or converting text to vector outlines.

Method 1: Embed Fonts in Your PDF (Preferred for Body Copy)

Exporting to PDF/X-1a or PDF/X-4 from Adobe InDesign or Illustrator automatically embeds font subsets directly inside the PDF container, keeping text sharp while preserving searchability and proper stroke weight.

  1. Choose File → Export → Adobe PDF (Print).
  2. Select PDF/X-1a:2001 or PDF/X-4:2008.
  3. Open the exported PDF in Adobe Acrobat and visit File → Properties → Fonts.
  4. Confirm every listed typeface shows Embedded or Embedded Subset.

Method 2: Convert Text to Outlines (Best for Logos & Illustrator Art)

Converting type to outlines turns each letterform into a mathematical vector shape with zero font dependency. Use this for standalone logos, signage graphics, or native .ai / .eps submissions.

In Adobe Illustrator

  1. Select all type (Ctrl/Cmd + A).
  2. Choose Type → Create Outlines (Shift + Ctrl/Cmd + O).
  3. Save as a new _outlined.ai or PDF copy.

In Adobe InDesign

  1. Select target text frames.
  2. Choose Type → Create Outlines.
  3. Keep your live-type .indd master intact.
Always Save an Unoutlined Backup: Once type is converted to outlines, it can no longer be spellchecked or edited as text. Save a separate copy with “_PRINT” or “_OUTLINED” in the filename before converting.

Choosing Fonts That Survive Press Ink

  • Minimum point sizes: Keep standard dark body copy at 6–7 pt minimum (8–10 pt ideal for catalogs and brochures).
  • Watch hairlines & ultra-lights: Very thin serifs or light weights can break up or fill in on uncoated paper stocks.
  • Reversed-out white text: When placing white type on rich dark colors, bump the weight up (Regular → Medium) and keep type 8 pt+ to offset ink spread.
  • Rich black caution: Never build small body text (<14 pt) out of 4-color CMYK black; use 100% K only so minor press registration never blurs letter edges.

Font Licensing Note

Commercial fonts are licensed software. Most foundries permit subset embedding in press-ready PDFs or outlining for commercial output, while prohibiting sending raw .otf / .ttf font files to third parties without a multi-seat license. Exporting a PDF/X with embedded fonts keeps both licensing and press output clean.
